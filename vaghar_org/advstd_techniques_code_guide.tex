\paragraph{Naming mismatch.} The code's internal numbering does not line
up with the paper's. \src{run.jl} labels MIP Start as ``Technique~1'',
Branch Priorities as ``2'', LP Basis as ``3'', Bound Tightening as
``4'', Variable Hints as ``5'', N2 Relaxation as ``6'' (see
\src{run.jl:642--650}). The paper's \texttt{advstd\_techniques.tex}
renumbers to the four safe techniques only (T1 Branch Priorities,
T2 Bound Tightening, T3 Variable Hints, T4 N2 Relaxation) and omits
MIP Start / LP Basis entirely. This guide uses the \textbf{paper}
numbering throughout.

\section{Two-Phase Orchestration}
\label{sec:phases}

\subsection{Phase 1: solve $N_1$ and serialise state}

Entry point \src{run.jl:389--390} dispatches mode
\texttt{advanced\_standard\_n1} to
\src{main\_advanced\_standard\_n1} (\src{run.jl:960--1063}). Phase~1
does three things per $(c_s, c_t)$ pair:

\begin{enumerate}[noitemsep]
  \item Solve $N_1$'s standard-mode MIP exactly like baseline VHAGaR,
    with \tech{hyper\_attack} PGD hints and (optionally) perturbed
    interval constraints and VHAGaR dependency constraints.
  \item Extract the primal solution, the \src{layers\_info\_dict}
    (per-neuron big-$M$ bounds), Gurobi's LP basis (\src{VBasis}),
    and Gurobi's per-variable pseudo-cost statistics.
  \item Serialise all of the above to \flag{n1\_state\_dir} with
    \src{save\_n1\_state} and \src{save\_n1\_diff\_bounds}.
\end{enumerate}

Key excerpt (\src{run.jl:1048--1053}):
\begin{lstlisting}[style=jl]
n1_var_names, n1_var_values = extract_all_variable_values(m_n1)
n1_layers_info   = deepcopy(layers_info_dict)
n1_vbasis        = extract_vbasis(m_n1)
n1_pseudocosts   = extract_pseudocosts(m_n1)
save_n1_state(n1_state_dir, c_tag, c_target,
              n1_var_names, n1_var_values, n1_layers_info,
              n1_vbasis; n1_pseudocosts=n1_pseudocosts)
\end{lstlisting}

The state layout on disk (see \src{save\_n1\_state} at
\src{utils/hyper\_attack.jl:370--384}):
\begin{itemize}[noitemsep]
  \item \src{n1\_vars\_\{ct\}\_\{ctt\}.bin} — paired vectors
    \src{(names, values)}.
  \item \src{n1\_layers\_\{ct\}\_\{ctt\}.bin} — the
    \src{layers\_info\_dict} dict \src{(layer, neuron) $\to$ (u, l,
    var\_index)}.
  \item \src{n1\_vbasis\_\{ct\}\_\{ctt\}.bin} — per-variable
    \src{VBasis} ints.
  \item \src{n1\_pseudocosts\_\{ct\}\_\{ctt\}.bin} — per-binary
    \src{NamedTuple(pd\_down, pd\_up, n\_down, n\_up)}.
  \item \src{diff\_bounds.bin} — per-ReLU-layer diff bounds (shared
    across all $(c_s, c_t)$).
  \item \src{n1\_preact\_bounds.bin} — per-ReLU-layer $N_1$
    pre-activation bounds (optional; required by Source~B of T2).
\end{itemize}

\subsection{Phase 2: sweep $N_2$ reusing $N_1$ state}

Entry point \src{run.jl:391--392} dispatches
\texttt{advanced\_standard\_n2} to
\src{main\_advanced\_standard\_n2} (\src{run.jl:1065--1072}), which is
just a wrapper that forwards to \src{main\_advanced\_standard}
(\src{run.jl:609--953}). The same function also serves as
\texttt{mode=advanced\_standard} when run in a single process
(solving $N_1$ in-line and then sweeping $N_2$).

Phase~2 is structured as:
\begin{enumerate}[noitemsep]
  \item Parse the technique flags into local booleans
    (\src{run.jl:615--630}).
  \item Precompute T2 diff bounds once, before the $(c_s, c_t)$ loop
    (\src{run.jl:702--751}). This runs Source~A, optionally Source~B,
    optionally Source~C, and never re-runs for subsequent class pairs.
  \item For each class pair, load $N_1$ state, build $N_2$'s MIP with
    T2/T4 applied during construction (\src{get\_model}), then
    optionally apply T1 and T3 to the already-built model before
    \src{optimize!} (\src{run.jl:855--945}).
\end{enumerate}

\section{Technique~1 — Branch Priorities \tech{(bp=bounds)}}
\label{sec:t1}

\textbf{Flag:} \flag{adv\_std\_branch\_priorities bounds}.\quad
\textbf{File:} \src{utils/help\_functions.jl:307--324}.

For every binary $a_{m,k}$ in the already-built $N_2$ MIP, look up
$N_1$'s \src{layers\_info} entry \src{(u, l, \_)} by matching the
\texttt{\_layer\_neuron} suffix of the variable name, compute the raw
gap $g = |u - l|$, and set Gurobi's \src{BranchPriority}:

\begin{lstlisting}[style=jl]
# help_functions.jl:307-324
function apply_n1_branch_priorities!(m_n2, n1_layers_info)
    applied = 0
    for v in JuMP.all_variables(m_n2)
        if JuMP.is_binary(v)
            vname = JuMP.name(v)
            for ((layer, neuron), (u, l, _)) in n1_layers_info
                if occursin("_$(layer)_$(neuron)", vname) &&
                   endswith(vname, "_$(layer)_$(neuron)")
                    gap = abs(u - l)
                    priority = gap < 1.0 ? 10 :
                               (gap < 5.0 ? 5 : 1)
                    MOI.set(JuMP.backend(m_n2),
                        Gurobi.VariableAttribute("BranchPriority"),
                        JuMP.index(v), priority)
                    applied += 1
                    break
                end
            end
        end
    end
end
\end{lstlisting}

\textbf{Invoked at} \src{run.jl:926--930}, after \src{mip\_set\_attr}
has attached Gurobi as the backend (this ordering is mandatory; the
\src{BranchPriority} attribute requires Gurobi to be bound).

\paragraph{Soundness.} Pure Gurobi attribute; no constraint added.
$\mathcal{F}_{\text{MIP}}$ is unchanged.

\section{Technique~2 — Bound Tightening \tech{(boundTight)}}
\label{sec:t2}

Technique~2 is the most complex technique. It runs \emph{before} the
$N_2$ MIP is built and populates several globals that the MIP
construction (\src{relu} in \src{core\_ops.jl}) reads when building the
big-$M$ encoding of each ReLU.

\subsection{Method~1 — interval arithmetic (baseline)}

\textbf{File:} \src{utils/perturbation\_intervals.jl:1009--1230}.

\src{compute\_diff\_and\_comp\_bounds} walks through $N_1$ and $N_2$
layer by layer, maintaining four interval state vectors:

\begin{itemize}[noitemsep]
  \item \src{diff\_up}, \src{diff\_down}: bounds on
    $\hat{z}^{N_2}_{m,k} - \hat{z}^{N_1}_{m,k}$.
  \item \src{pert\_up}, \src{pert\_down}: bounds on the
    perturbation-induced diff inside a single network.
  \item \src{n1\_act\_up}, \src{n1\_act\_down}: $N_1$'s post-ReLU bounds.
  \item \src{n1\_pre\_up\_cur}, \src{n1\_pre\_down\_cur}: $N_1$'s
    pre-activation bounds at the most recent Linear/Conv layer.
\end{itemize}

Per the paper formula
$\hat{z}^{N_2}_{m,k} - \hat{z}^{N_1}_{m,k} = W_2\,(\text{prev diff}) +
\Delta W \cdot z^{N_1}_{m-1} + \Delta b$, the Linear update is:

\begin{lstlisting}[style=jl]
# perturbation_intervals.jl:1056-1082 (elided)
elseif occursin("Linear", string(typeof(l)))
    W1 = Float64.(transpose(l.matrix))
    W2 = Float64.(transpose(l2.matrix))
    ΔW = W2 - W1;  Δb = b2 - b1
    r1_min, r1_max = interval_matrix_vector_multiplication(
        ΔW, ΔW, n1_act_down, n1_act_up)           # ΔW · a_n1
    r2_min, r2_max = interval_matrix_vector_multiplication(
        W2, W2, diff_down, diff_up)               # W2 · prev_diff
    diff_down = r1_min .+ r2_min .+ Δb
    diff_up   = r1_max .+ r2_max .+ Δb
\end{lstlisting}

ReLU clipping is done at \src{perturbation\_intervals.jl:1120--1170}.
It has two modes — default (non-expansive $d^\uparrow \leftarrow
\max(0, d^\uparrow)$, $d^\downarrow \leftarrow -\max(0, -d^\downarrow)$)
and \src{optimizing\_intervals=true} (tighter per-neuron clipping using
the concurrent $N_1$ and $N_2$ stability).

\subsection{Method~2 — zonotope bounds}

\textbf{Flag:} \flag{adv\_std\_zono\_bounds true}.\quad
\textbf{Files:}
Source~A in \src{perturbation\_intervals.jl:1317--1740};
Source~B in \src{perturbation\_intervals.jl:1765--1988}.

\paragraph{Source~A — diff zonotope
(\src{compute\_diff\_bounds\_zonotope}).} Tracks per-layer
\src{diff\_center} (vector) and \src{diff\_gens} (matrix, rows =
neurons, columns = shared noise $\epsilon_j$). Affine update
concatenates correlated ($W_2 \cdot G_{m-1}$) and independent
($\Delta W \cdot \mathrm{diag}(\mathrm{rad})$) generators:

\begin{lstlisting}[style=jl]
# perturbation_intervals.jl:1402-1413
new_center      = W2 * diff_center .+ ΔW * n1_center .+ Δb
new_gens_corr   = W2 * diff_gens
new_gens_indep  = ΔW * diagm(n1_radius)
diff_gens       = hcat(new_gens_corr, new_gens_indep)
diff_center     = new_center
\end{lstlisting}

DeepZ ReLU relaxation for split neurons (\src{perturbation\_intervals.jl:1612--1622}):
\begin{lstlisting}[style=jl]
# Generic split case: λ·z + μ ± μ·ε_new
λ = u_d / (u_d - l_d)
μ = -u_d * l_d / (2.0 * (u_d - l_d))
diff_center[i] = λ * diff_center[i] + μ
diff_gens[i, :] .*= λ
new_col = zeros(n);  new_col[i] = μ
push!(new_gen_cols, new_col)
\end{lstlisting}

\paragraph{Source~B — absolute $N_2$ zonotope
(\src{compute\_n2\_bounds\_zonotope\_with\_n1\_tighten}).} A separate
zonotope propagating $N_2$'s \emph{absolute} values from
$[0, 1]^n \pm \ep$. At each ReLU layer the hull is intersected with
Source~A's bounds before applying DeepZ:

\begin{lstlisting}[style=jl]
# perturbation_intervals.jl:1910-1934
# 1. hull of current zonotope
abs_sum = vec(sum(abs.(gens), dims=2))
u_hull  = center .+ abs_sum
l_hull  = center .- abs_sum
# 2. intersect with Source A: [n1_preact + diff_down, n1_preact + diff_up]
u_fromA = n1_up .+ diff_up
l_fromA = n1_dn .+ diff_dn
if length(u_fromA) == length(u_hull)
    u_tight = min.(u_hull, u_fromA)
    l_tight = max.(l_hull, l_fromA)
end
# 3. store, then apply DeepZ ReLU with [l_tight, u_tight]
push!(n2_abs_up_bounds,   copy(u_tight))
push!(n2_abs_down_bounds, copy(l_tight))
\end{lstlisting}

\subsection{Method~3 — N1 probe LP (Source C)}

\textbf{Flag:} \flag{adv\_std\_n1\_probe lp}.\quad
\textbf{File:} \src{utils/n1\_probe\_lp.jl:158--408}.

The probe builds a \emph{fresh} pure-LP JuMP model containing
triangle-relaxed forward passes of \emph{both} $N_1$ and $N_2$ sharing
the same input variables $v_\mathrm{in}, v_{x_0}$. The input link
constraint is perturbation-specific and dispatched by
\src{\_setup\_probe\_inputs} (\src{n1\_probe\_lp.jl:49--156}), which
handles \texttt{linf}, \texttt{brightness}, \texttt{contrast},
\texttt{patch}, \texttt{occ}, and \texttt{translation}. Rotation is
not supported and Source~C silently skips.

The triangle ReLU is emitted inside
\src{forward\_pass\_triangle\_relaxed} (lines 226--281):

\begin{lstlisting}[style=jl]
# n1_probe_lp.jl:255-270
for i in 1:n_neurons
    u_i = u_r[i];  l_i = l_r[i]
    if u_i <= 0.0
        post_flat[i] = zero(JuMP.AffExpr)
    elseif l_i >= 0.0
        post_flat[i] = flat_state[i]
    else
        v = @variable(m, lower_bound=0.0, upper_bound=max(0.0, u_i))
        @constraint(m, v >= flat_state[i])
        @constraint(m, v >= 0.0)
        @constraint(m, v <= (u_i / (u_i - l_i)) * (flat_state[i] - l_i))
        post_flat[i] = v
    end
end
\end{lstlisting}

OBBT loops run \src{optimize!} twice per pre-activation neuron (min and
max), for both the clean and perturbed copies of $N_2$:

\begin{lstlisting}[style=jl]
# n1_probe_lp.jl:301-317 (org copy; pert copy is symmetric)
for r in 1:length(n2_org_handles)
    for k in 1:length(n2_org_handles[r])
        @objective(m_probe, Min, n2_org_handles[r][k])
        optimize!(m_probe)
        if termination_status(m_probe) in (MOI.OPTIMAL, MOI.LOCALLY_SOLVED)
            n2_probe_down_bounds_org[r][k] = objective_value(m_probe)
        end
        @objective(m_probe, Max, n2_org_handles[r][k])
        optimize!(m_probe)
        if termination_status(m_probe) in (MOI.OPTIMAL, MOI.LOCALLY_SOLVED)
            n2_probe_up_bounds_org[r][k] = objective_value(m_probe)
        end
    end
end
\end{lstlisting}

The probe's bounds flow into the four
\src{n2\_probe\_\{up,down\}\_bounds\_\{org,pert\}} globals, which the
MIP's \src{relu} reads during N2 construction (see
Section~\ref{sec:t2_integration}).

\subsection{Final bound integration}
\label{sec:t2_integration}

\textbf{Handoff:} After the Phase-2 pre-compute,
\src{run.jl:857--860} calls \src{set\_n1\_neuron\_bounds}
(\src{help\_functions.jl:267--273}) to freeze $N_1$'s
\src{layers\_info\_dict} into the \src{n1\_neuron\_bounds} global keyed
by \src{(layer, neuron)}.

\src{get\_model} then builds the $N_2$ MIP and, at every split ReLU,
\src{relu} consults the globals populated by T2 to intersect all
available sources before emitting the big-$M$ constraints
(\src{core\_ops.jl:578--598}). This is where the $\min/\max$ in
\texttt{advstd\_techniques.tex}, Eqs.~(3)--(4) live operationally: each
source is a term in the final $\min/\max$ that happens as the
MIPVerify framework tightens its bound before emitting the big-$M$.

When the tightened interval is single-signed,
\src{relu} short-circuits and returns either $x$ (always active) or
$0$ (always inactive) at the top of the function
(\src{core\_ops.jl:301--303}), removing the binary entirely.

\section{Technique~3 — Variable Hints \tech{(varHint)}}
\label{sec:t3}

\textbf{Flag:} \flag{adv\_std\_var\_hint true}.\quad
\textbf{File:} \src{utils/help\_functions.jl:401--430}
(helpers at 334--362).

\paragraph{Step 1 — pseudo-cost score.} From the saved $N_1$ pseudo-cost
dict, compute per-variable score $s_i = p_i^\downarrow n_i^\downarrow
+ p_i^\uparrow n_i^\uparrow$:

\begin{lstlisting}[style=jl]
# help_functions.jl:334-340
function compute_n1_var_scores(n1_pseudocosts)
    scores = Dict{String, Float64}()
    for (name, pc) in n1_pseudocosts
        scores[name] = pc.pd_down * pc.n_down + pc.pd_up * pc.n_up
    end
    return scores
end
\end{lstlisting}

\paragraph{Step 2 — rank to integer priority.} Sort nonzero scores
descending, map rank to $[1, 100]$:

\begin{lstlisting}[style=jl]
# help_functions.jl:349-362
function rank_to_priority(scores; max_pri=100)
    priorities = Dict{String, Int}()
    nonzero = sort([n for (n, s) in scores if s > 0]; by=n -> -scores[n])
    n_rank = length(nonzero)
    for (rank, name) in enumerate(nonzero)
        priorities[name] = max(1,
            round(Int, max_pri * (1 - (rank - 1) / n_rank)))
    end
    for (name, s) in scores
        if s <= 0; priorities[name] = 0; end
    end
    return priorities
end
\end{lstlisting}

\paragraph{Step 3 — set \src{VarHintVal} and \src{VarHintPri} on $N_2$.}

\begin{lstlisting}[style=jl]
# help_functions.jl:418-429
for v in JuMP.all_variables(m_n2)
    if !JuMP.is_binary(v); continue; end
    name  = JuMP.name(v)
    value = get(value_by_name, name, nothing)
    if value === nothing; continue; end
    pri = get(priority_by_name, name, 0)
    MOI.set(JuMP.backend(m_n2),
        Gurobi.VariableAttribute("VarHintVal"), JuMP.index(v), value)
    MOI.set(JuMP.backend(m_n2),
        Gurobi.VariableAttribute("VarHintPri"), JuMP.index(v), pri)
end
\end{lstlisting}

If pseudo-costs are not available (legacy saved state), the code
falls back to a uniform priority~10 per
\src{help\_functions.jl:412--414}.

\paragraph{Invoked at} \src{run.jl:932--935}, independent of the
\src{bp\_mode} setting — T1 and T3 can both be active simultaneously.

\section{Technique~4 — N2 Triangle Relaxation \tech{(relaxT)}}
\label{sec:t4}

\textbf{Flag:} \flag{adv\_std\_n2\_relax\_threshold $\tau$} (default
$-1.0$ disables).\quad
\textbf{File:} \src{utils/MIPVerify.jl/src/net\_components/core\_ops.jl:547--576}.

The gap-area scoring helper is defined once at the top of the
\src{relu} function (line 308):

\begin{lstlisting}[style=jl]
_tri_gap(l_val, u_val) =
    (l_val >= 0.0 || u_val <= 0.0) ? 0.0 :
    u_val * (-l_val) / (2.0 * (u_val - l_val))
\end{lstlisting}

The advstd relaxation branch fires only in standard-mode copies
(\texttt{org}/\texttt{perturbation}), and only when
\src{n1\_neuron\_bounds} is populated (i.e.\ T2 is active):

\begin{lstlisting}[style=jl]
# core_ops.jl:547-576
if adv_std_n2_relax_threshold >= 0.0 &&
   (network_version == "org" || network_version == "perturbation") &&
   !isempty(n1_neuron_bounds)
    key = (neurons_names.layer, neurons_names.neuron)
    if haskey(n1_neuron_bounds, key)
        (n1_u_val, n1_l_val) = n1_neuron_bounds[key]
        n1_score = _tri_gap(n1_l_val, n1_u_val)
        if n1_score <= adv_std_n2_relax_threshold
            av = JuMP.all_variables(model)
            push!(layers_info_dict,
                  (neurons_names.layer, neurons_names.neuron) =>
                      (u, l, length(av)))
            x_rect = @variable(model)
            set_lower_bound(x_rect, 0.0)
            set_upper_bound(x_rect, max(0.0, u))
            set_name(x_rect, string(network_version,
                "x_rect_n1relax_advstd_",
                "layerCount", layer_counter,
                "_neuronCount", nueron_counter,
                "_", neurons_names.layer, "_", neurons_names.neuron))
            @constraint(model, x_rect >= 0)
            @constraint(model, x_rect >= x)
            @constraint(model, x_rect <= (u / (u - l)) * (x - l))
            if network_version == "org"
                global n_n2_relaxed_binaries_org += 1
            else
                global n_n2_relaxed_binaries_pert += 1
            end
            return x_rect
        end
    end
end
\end{lstlisting}

Key property, matching the paper: the \emph{decision} uses
$N_1$'s bounds (via \src{n1\_neuron\_bounds}) while the triangle
\emph{constraints} use $N_2$'s tightened \src{(u, l)} produced by T2.
Relaxed ReLUs still push an entry to \src{layers\_info\_dict} (with the
variable index but no companion binary), keeping downstream code that
iterates that dict unbroken.

\paragraph{Guard.} \src{run.jl:627--631} warns if the user sets
$\tau \ge 0$ without \flag{adv\_std\_bound\_tightening true}, because
then \src{n1\_neuron\_bounds} would be empty and the check at
\src{core\_ops.jl:549} silently disables the whole technique.

\section{Perturbed Interval Constraints (\flag{use\_perturbed\_intervals})}
\label{sec:pi}

\textbf{File:} \src{utils/perturbation\_intervals.jl:634--708}.

Always enabled in the safe combinations (in Phase~1 and Phase~2).
Propagates interval bounds on $z^+_{\mathrm{pert}} - z^+_{\mathrm{org}}$
through a single network, then adds inequality-pair constraints that
link the org and perturbation copies of every split ReLU post-ReLU
variable:

\begin{lstlisting}[style=jl]
# perturbation_intervals.jl:674-703
elseif occursin("ReLU", string(typeof(l)))
    layer_cnt += 1
    # σ(z+Δ) - σ(z) ∈ [min(0, Δ_down), max(0, Δ_up)]
    I_pert_up_local   = max.(0.0, I_pert_up_local)
    I_pert_down_local = .- max.(0.0, .- I_pert_down_local)
    # collect x_rect vars in the org / pert copies of this ReLU layer
    vec_clean = [n for n in eachindex(av)
        if occursin(clean_prefix * "x_rect_layerCount" * string(layer_cnt),
                    JuMP.name(av[n]))]
    vec_pert  = [n for n in eachindex(av)
        if occursin(pert_prefix * "x_rect_layerCount" * string(layer_cnt),
                    JuMP.name(av[n]))]
    if length(vec_clean) > 0 && length(vec_pert) > 0
        constraints_added += add_matched_interval_constraints!(
            m, av, vec_clean, vec_pert,
            ensure_1d(I_pert_up_local), ensure_1d(I_pert_down_local))
    end
end
\end{lstlisting}

The constraints are (\src{perturbation\_intervals.jl:144--146}):
\[
  \text{av}[\text{pert}] \le \text{av}[\text{clean}] + I^\uparrow,
  \quad
  \text{av}[\text{pert}] \ge \text{av}[\text{clean}] + I^\downarrow.
\]

\paragraph{Invoked at} \src{run.jl:917--920} for $N_2$ and
\src{run.jl:808--810} for $N_1$.

\section{Bugs and Latent Hazards}
\label{sec:bugs}

The following issues were identified while reading the implementation
against the paper description. Each item notes the recommended fix and
current status. Bugs~1 and~2 are still open; Bugs~3, 4, 6, 7, and the
Source~B non-bug note have since been addressed in-place (dates
below); Bug~5 has been addressed via an \emph{opt-in} flag
(\flag{adv\_std\_var\_hint\_fix}) so existing sweep results remain
reproducible. Open bugs are listed first, then fixed bugs.

\subsection{Bug~1: documentation mismatch in \texttt{run.jl} technique labels}

\textbf{File:} \src{run.jl:642--650}, also the help text at
\src{run.jl:298--356}.

\textbf{Symptom.} The \texttt{println} labels and \texttt{--help}
output number the techniques (``Technique 1 (MIP Start)'',
``Technique 2 (Branch Priorities)'', \ldots) using the old internal
numbering. The paper \texttt{advstd\_techniques.tex} renumbers to
\emph{only} the four safe techniques (T1--T4) and deliberately drops
MIP Start and LP Basis. Readers cross-referencing the paper will be
confused when the log says ``Technique 5 (Variable Hints)'' even
though the paper calls it T3.

\textbf{Fix.} Update the log strings and help text to match the paper
numbering (T1 Branch Priorities, T2 Bound Tightening, T3 Variable
Hints, T4 N2 Relaxation, and label MIP Start / LP Basis as
``unsafe / not in safe combos''). Alternatively, leave the code
numbering alone but add a sentence near line~642 explaining that these
codes predate the paper.

\subsection{Bug~2: \src{apply\_n1\_branch\_priorities!} does double work}

\textbf{File:} \src{utils/help\_functions.jl:313}.

\textbf{Symptom.}
\begin{lstlisting}[style=jl]
if occursin("_$(layer)_$(neuron)", vname) &&
   endswith(vname, "_$(layer)_$(neuron)")
\end{lstlisting}
\src{endswith} already implies \src{occursin} for the same needle, so
the \src{occursin} call is pure overhead. With a few thousand binaries
$\times$ a few thousand \src{layers\_info} entries per call, the double
scan matters in the inner loop.

\textbf{Fix.} Drop the \src{occursin} clause; \src{endswith} alone is
both necessary and sufficient for the disambiguation this function
needs. (Mere micro-optimisation — no correctness impact.)

\subsection{[FIXED] Bug~3: silent skip when Source~C prerequisites are missing}

\textbf{File:} \src{utils/n1\_probe\_lp.jl:176--196}.

\textbf{Symptom.} If \flag{adv\_std\_n1\_probe lp} is requested but
\src{n1\_preact\_up\_bounds} or \src{relu\_diff\_up\_bounds} are empty
(e.g.\ Phase~1 was run without also calling
\src{compute\_diff\_and\_comp\_bounds}, or a rotation perturbation is
used), the function printed a one-line \texttt{println} and returned
without populating the probe globals. The outer flow in
\src{run.jl:898--902} still appended a
\texttt{\_elimOrg0\_elimPert0} suffix to the filename as though the
probe had run, and the MIP solve proceeded without Source~C
tightening. Result files with \texttt{\_n1ProbeLP} in their name could
therefore represent runs where Source~C silently did nothing.

\textbf{Fix (applied).} Abort the whole Phase~2 invocation when the
probe is requested but cannot run --- no MIP solve, no result file
written. This differs from the guide's originally-proposed
\src{@warn} fix: users care about clean sweep bookkeeping more than
about best-effort fallback, so we strictly refuse to produce a result
that would misrepresent the combo.

\textbf{Status.} FIXED 2026-04-19 at
\src{utils/n1\_probe\_lp.jl:176--196} and \src{run.jl:761--772}.
\src{compute\_n2\_bounds\_n1\_probe\_lp} now returns \src{Bool}
(\src{true} on success, \src{false} on any of the four skip paths).
Phase~2 checks the return value and, when the probe was requested but
returned \src{false}, prints a clear \texttt{ERROR:} message and
\src{return}s from \src{main\_advanced\_standard} before the c\_target
loop --- so no \src{optimize!} runs and no \src{save\_results} is
called. In the sweep driver, affected combos (most notably
\texttt{rotation} perturbation with \texttt{probe=lp}) will simply not
produce result files; \src{\_advstd\_result\_exists} will keep
returning \src{false} for them, making the gap visible rather than
pretending the combo was measured.

\subsection{[FIXED] Bug~4: substring collision in \src{perturbed\_interval\_constraints} layer matching}

\textbf{File:} \src{utils/perturbation\_intervals.jl:685, 693}.

\textbf{Symptom.} The code collects per-layer \src{x\_rect} variables
by substring:
\begin{lstlisting}[style=jl]
occursin(clean_prefix * "x_rect" * "_" * "layerCount" * string(layer_cnt),
         JuMP.name(av[n]))
\end{lstlisting}
For \src{layer\_cnt = 1} the substring \texttt{"orgx\_rect\_layerCount1"}
is also a prefix of \texttt{"orgx\_rect\_layerCount10\_..."}, so
variables belonging to ReLU layer~10, 11, \ldots\ match the layer~1
pattern. The constraints added via
\src{add\_matched\_interval\_constraints!} then pair \emph{different}
ReLU layers under the same interval bounds, producing either (a)
over-constrained infeasible MIPs when the bounds conflict, or (b)
silently wrong (loose in one direction, tight in the other) constraints
that still happen to be sound because of the clipping at
\src{perturbation\_intervals.jl:679--680}.

\textbf{Exposure.} All current MNIST models in the repo (3x10, 4x10,
5x10, cnn0--cnn3) have $\le 6$ ReLU layers, so the collision never
triggers on the tables in the paper. Any future architecture with
$\ge 10$ ReLU layers will hit the bug.

\textbf{Fix.} Disambiguate by appending the next separator to the
pattern so \texttt{"layerCount1"} only matches \texttt{"layerCount1\_"}:
\begin{lstlisting}[style=jl]
occursin(clean_prefix * "x_rect_layerCount" * string(layer_cnt) * "_",
         JuMP.name(av[n]))
\end{lstlisting}
(The \src{endswith(\_, "\_$(layer)\_$(neuron)")} guard used in
\src{apply\_n1\_branch\_priorities!} at
\src{help\_functions.jl:313} is immune to the same bug because
\src{endswith} is a full-suffix test, not a substring test.)

\textbf{Status.} FIXED 2026-04-19 at
\src{utils/perturbation\_intervals.jl:685, 693} (trailing \texttt{\_}
appended to both clean and perturbed layer-match patterns in
\src{perturbed\_interval\_constraints}). The same collision pattern
survives in four sister sites in the same file (lines 408, 416, 607,
615) in other interval / distillation functions and has not yet been
patched.

\subsection{[FIXED OPT-IN] Bug~5: \texttt{VarHintVal} set without checking variable bounds}

\textbf{File:} \src{utils/help\_functions.jl:418--428}.

\textbf{Symptom.} \src{apply\_n1\_var\_hints!} blindly copies
$N_1$'s \src{JuMP.value(v)} as the hint value for every matching
binary in $N_2$. After T2 bound tightening has eliminated some
binaries (\src{n1\_neuron\_bounds} collapsed their interval to
single-signed), those variables simply don't exist in $N_2$'s
\src{JuMP.all\_variables} and the loop skips them via the
\src{get(value\_by\_name, name, nothing)} check. But for \emph{other}
binaries whose $N_2$ encoding was replaced by a triangle relaxation
(T4), the variable name now starts with
\src{\{version\}x\_rect\_n1relax\_advstd\_...} (see
\src{core\_ops.jl:561--564}), which does \emph{not} appear in
\src{n1\_var\_names} (that suffix was never in $N_1$). So T4-relaxed
neurons are silently un-hinted; fine. But the paired
\src{\{version\}a\_...} binary is missing altogether, so the score
accounting in \src{rank\_to\_priority} (which ranks based on the full
$N_1$ pseudo-cost dict) still assigns priority to non-existent $N_2$
binaries and wastes cycles matching them. Cosmetic; no correctness
impact.

\textbf{Fix.} Filter \src{n1\_pseudocosts} down to names that survive
in $N_2$ before calling \src{rank\_to\_priority} so the priority
distribution is computed over the actual hintable set, not the
pre-relaxation superset.

\textbf{Status.} ADDRESSED OPT-IN 2026-04-19 via the new
\flag{adv\_std\_var\_hint\_fix} flag (default \texttt{false}). When
enabled alongside \flag{adv\_std\_var\_hint true}, the flag walks
\src{JuMP.all\_variables(m\_n2)}, collects the set of names that are
still binary in $N_2$, and filters \src{n1\_pseudocosts} to that set
before \src{rank\_to\_priority} at
\src{utils/help\_functions.jl:415--430}. The filename suffix
\texttt{\_varHintFix} is appended (in addition to the existing
\texttt{\_varHint}) so A/B comparisons against pre-fix sweep
results are unambiguous. The parallel sweep driver
(\src{run\_relaxation\_sweep.py}) accepts
\flag{sweep\_adv\_std\_var\_hint\_fix} and auto-prunes
\texttt{vhf=true $\land$ vh=false} combos. Note: pre-fix varHint
results are \emph{sound} (the fix affects hint \emph{priority} only, not
hint \emph{value} or the solved $\delta$), but solve times and hence
win/tie/loss categorisations may shift slightly under the fix.

\subsection{[FIXED] Bug~6: \src{adv\_std\_lp\_basis} defaults to true even though it's never safe with bound tightening}

\textbf{File:} \src{run.jl:319--323}.

\textbf{Symptom.} The default for \flag{adv\_std\_lp\_basis} is
\texttt{true}, and the default for \flag{adv\_std\_bound\_tightening}
is also \texttt{true}. Users running \src{main\_advanced\_standard}
with no flags get a warning \texttt{"apply\_vbasis!: skipped
(incompatible with bound tightening)"} (\src{run.jl:942}) on every
class pair — the basis is loaded from disk, the pointer is threaded
through the call chain, and then silently discarded. No correctness
issue but noisy and surprising.

\textbf{Fix.} Change the default of \flag{adv\_std\_lp\_basis} to
\texttt{false}, or make the flag auto-disable when
\flag{adv\_std\_bound\_tightening} is \texttt{true}.

\textbf{Status.} FIXED 2026-04-19 at \src{run.jl:327--334}. The flag
default is now \texttt{false} and the help text explicitly notes the
flag is a no-op when \flag{adv\_std\_bound\_tightening} is
\texttt{true}. Users who want LP-basis transfer must opt in
explicitly. Prior sweep results (where every combo was silently
tagged \texttt{\_lpBasis} with the basis never actually applied) are
sound but measurement-identical across \texttt{lb=true}/\texttt{lb=false}
for \texttt{bt=true} rows; new sweeps will no longer produce that
duplication by default. The parallel default in
\src{run\_relaxation\_sweep.py:1860} still reads \texttt{["true"]} —
left as-is to avoid silently changing sweep behaviour for existing
invocations that rely on it.

\subsection{[FIXED] Bug~7: \src{apply\_vbasis!} calls MOI.set on the JuMP model, not the backend}

\textbf{File:} \src{utils/hyper\_attack.jl:352}.

\textbf{Symptom.} The call is
\begin{lstlisting}[style=jl]
MOI.set(m_n2, Gurobi.VariableAttribute("VBasis"),
        JuMP.index(v), vbasis[name])
\end{lstlisting}
whereas every other Gurobi-attribute call in the codebase uses
\src{MOI.set(JuMP.backend(m\_n2), Gurobi.VariableAttribute(...))} —
for example \src{help\_functions.jl:316, 385, 425, 426}. When
\src{m\_n2} is a \src{JuMP.Model} (the common case), passing it
directly to \src{MOI.set} can fail with
\texttt{MOI.UnsupportedAttribute} or silently no-op depending on the
MOI bridging in use, defeating the purpose of LP-basis transfer.

\textbf{Fix.} Use the backend consistently:
\begin{lstlisting}[style=jl]
MOI.set(JuMP.backend(m_n2), Gurobi.VariableAttribute("VBasis"),
        JuMP.index(v), vbasis[name])
\end{lstlisting}
This matches the working pattern used by the other four
attribute-setting functions in the codebase.

\textbf{Status.} FIXED 2026-04-19 at
\src{utils/hyper\_attack.jl:352} --- \src{MOI.set} now takes
\src{JuMP.backend(m\_n2)} as its first argument, matching the working
pattern. Combined with Bug~6's fixed default, LP-basis transfer is now
functional on the \texttt{bt=false, lb=true} path for users who
explicitly enable it; prior \texttt{bt=false, lb=true} runs (if any)
likely no-op'd silently, so their timings may differ from post-fix
re-runs.

\subsection{[RESOLVED] Non-bug note: Source~B input coverage is looser than paper}

\textbf{File:} \src{utils/perturbation\_intervals.jl:1815--1816}.

The paper states Source~B initialises the absolute-$N_2$ zonotope
from ``$v_\mathrm{in} \in [0, 1]^n$ with perturbation~$\ep$''. The
code seeds from
\[
  c = 0.5,\quad r = 0.5 + \ep
\]
per pixel, so the initial hull is $[-\ep, 1+\ep]$ rather than
$[0, 1+\ep]$. This is intentional (single zonotope covers both clean
\emph{and} perturbed copies), sound, but \emph{slightly looser} at the
input layer than the paper suggests. Not a bug; worth a sentence in
the paper's description if precision matters.

\textbf{Status.} RESOLVED 2026-04-19 in the paper:
\src{advstd\_techniques.tex} Source~B paragraph now explicitly
describes the initial hull as $[-\ep,\, 1+\ep]^n$ and notes the
single-zonotope rationale. Code unchanged.
