\section{Key Ideas}
\label{sec:key_ideas}
%% ═══════════════════════════════════════════════════════════════════════════════

We present our key ideas for accelerating the MIP-based computation of $\hat{\delta}_{c_t}$.
For tightening the MIP's LP relaxation, we use \emph{Perturbed-interval constraints} and 
\emph{zonotope bound tightening}. Furthermore, we relax binaries of near-decided neurons 
using \emph{triangle relaxation over two networks}, 
and using a \emph{warm start from a previously verified network $N_\text{pre}$} 
for faster convergence of a target network $N$.

\paragraph{Perturbed-Interval Constraints.}
\label{sec:tech:pi}

We rely on VHAGaR's two-copy MIP encoding of the network: a clean copy on input $x \in [0,1]^n$ and a perturbed copy on $x_p = x + v_e$ with $v_e \in [-\ep,\ep]^n$. We introduce tight bounds between the two copies via \emph{perturbed-interval constraints} that prune the search space and improve the running times. Concretely, for each ReLU neuron $(m,k)$ shared by the two copies, we add the two linear inequalities
\begin{align}
  z^{\mathrm{pert}}_{m,k} &\le z^{\mathrm{org}}_{m,k} + \Delta^{\uparrow}_{m,k}, \label{eq:pi_upper}\\
  z^{\mathrm{pert}}_{m,k} &\ge z^{\mathrm{org}}_{m,k} + \Delta^{\downarrow}_{m,k}, \label{eq:pi_lower}
\end{align}
where $[\Delta^\downarrow_{m,k}, \Delta^\uparrow_{m,k}]$ is a sound interval over-approximation of the per-neuron post-ReLU drift. No new variables are introduced; nothing inside either copy's encoding changes.

We compute $[\Delta^\downarrow_{m,k}, \Delta^\uparrow_{m,k}]$ via a layer-by-layer interval recurrence over the network. We initialize at the input with the perturbation bound $[\Delta^{a,\downarrow}_0, \Delta^{a,\uparrow}_0] = [-\ep \mathbf{1},\, +\ep \mathbf{1}]$. For an affine layer with weight $W$, the bias cancels and interval arithmetic on $W^\top \Delta^a_{m-1}$ gives the pre-activation drift bounds:
\begin{align}
  \Delta^{z,\downarrow}_{m,k} &= \textstyle\sum_{k'} \min\!\bigl(W_{k',k}\, \Delta^{a,\downarrow}_{m-1,k'},\; W_{k',k}\, \Delta^{a,\uparrow}_{m-1,k'}\bigr), \nonumber \\
  \Delta^{z,\uparrow}_{m,k}   &= \textstyle\sum_{k'} \max\!\bigl(W_{k',k}\, \Delta^{a,\downarrow}_{m-1,k'},\; W_{k',k}\, \Delta^{a,\uparrow}_{m-1,k'}\bigr).
  \label{eq:pi_affine}
\end{align}
For a ReLU layer, the pointwise identity $\sigma(z+\Delta) - \sigma(z) \in [\min(0,\Delta), \max(0,\Delta)]$ yields
\begin{equation}
  \Delta^{a,\downarrow}_{m,k} = \min\!\bigl(0,\, \Delta^{z,\downarrow}_{m,k}\bigr), \quad
  \Delta^{a,\uparrow}_{m,k}   = \max\!\bigl(0,\, \Delta^{z,\uparrow}_{m,k}\bigr).
  \label{eq:pi_relu}
\end{equation}

\paragraph{Example.}
Consider an $\ell_\infty$ perturbation with $\ep = 0.1$ on a network whose first hidden ReLU neuron
$k$ at layer $m=1$ has incoming weight row $(w_{1,k}, w_{2,k}) = (1, -2)$. The input bound is $\Delta^a_0 \in [-0.1, 0.1]^2$. By \eqref{eq:pi_affine}, $\Delta^{z,\uparrow}_{1,k} = 0.1 + 0.2 = 0.3$ and $\Delta^{z,\downarrow}_{1,k} = -0.1 - 0.2 = -0.3$; \eqref{eq:pi_relu} then yields $[\Delta^{a,\downarrow}_{1,k}, \Delta^{a,\uparrow}_{1,k}] = [-0.3, 0.3]$. We therefore add to the MIP the constraints $z^{\mathrm{pert}}_{1,k} - z^{\mathrm{org}}_{1,k} \in [-0.3, 0.3]$, coupling the two copies' post-ReLU activations at this neuron. Figure~\ref{fig:pi_example} illustrates this propagation, with the weights on the shared edges and the per-edge arithmetic.

\paragraph{Zonotope Bound Tightening.}
\label{sec:tech:zono}

The MIP encodes each ReLU neuron $(m,k)$ with big-$M$ constants $\underline z_{m,k}, \overline z_{m,k}$ derived from per-neuron pre-activation bounds $[l_{m,k}, u_{m,k}]$. Loose bounds inflate the feasible region of every LP relaxation solved at the branch-and-bound nodes, and they keep binary variables alive on neurons that are already stable under all admissible inputs. Tighter bounds therefore shrink the search space directly, and they may flip a split neuron ($l_{m,k} < 0 < u_{m,k}$) to stable, dropping its binary $a_{m,k}$ from the MIP entirely. We obtain such tighter bounds by propagating a zonotope through the network and reading per-neuron hull bounds at each ReLU layer, which we then inject as the big-$M$ constants of the encoding.

A zonotope represents each pre-activation $\hat z_{m,k}$ as a centre plus a linear combination of shared noise variables $\eta_j \in [-1, 1]$ (distinct from the perturbation budget $\ep$), stored as a centre vector $\mathbf c_m \in \RR^K$ and a generator matrix $G_m \in \RR^{K \times p}$:
\begin{equation}
  \hat z_{m,k} \;=\; c_{m,k} + \textstyle\sum_{j=1}^{p} g_{m,k,j}\, \eta_j,
  \qquad
  \eta_j \in [-1, 1].
  \label{eq:zono_rep}
\end{equation}
Sharing $\eta_j$ across neurons of the same layer preserves correlations, so a downstream affine layer contributes the tighter half-width $|\sum_{k'} w_{k,k'}\, g_{m-1,k',j}|$ rather than the looser interval sum $\sum_{k'} |w_{k,k'}\, g_{m-1,k',j}|$ (with equality only when all terms share a sign). We initialise the zonotope so its hull covers both the clean input $v_\mathrm{in} \in [0, 1]^n$ and the perturbed input $v_{x_0} = v_\mathrm{in} + v_e \in [-\ep, 1+\ep]^n$ simultaneously. Let $r = \tfrac{1}{2} + \ep$ denote the per-coordinate half-width of the widened input box $[-\ep, 1+\ep]^n$; then
\begin{equation}
  \mathbf{c}_0 \;=\; \tfrac{1}{2}\mathbf{1},
  \qquad
  G_0 \;=\; r\, I_n \;\in\; \RR^{n \times n},
  \label{eq:zono_init}
\end{equation}
so a single pass through the network bounds the pre-activations under both copies at once.

For an affine layer with weight $W$ and bias $b$, the zonotope propagates exactly: $\mathbf c \leftarrow W \mathbf c + b$ and $G \leftarrow W G$. For a ReLU layer, we apply the standard DeepZ relaxation~\cite{singh2018fast}, with per-neuron hull endpoints
\begin{equation}
  l_k \;=\; c_{m,k} - \textstyle\sum_j |g_{m,k,j}|,
  \qquad
  u_k \;=\; c_{m,k} + \textstyle\sum_j |g_{m,k,j}|.
  \label{eq:zono_hull}
\end{equation}
Stable neurons ($u_k \le 0$ or $l_k \ge 0$) pass through unchanged or are zeroed; split neurons ($l_k < 0 < u_k$) are scaled by $\lambda_k = u_k / (u_k - l_k)$ and offset by $\mu_k = -u_k l_k / \bigl(2(u_k - l_k)\bigr)$:
\begin{equation}
  c_{m,k} \leftarrow \lambda_k\, c_{m,k} + \mu_k,
  \qquad
  g_{m,k,\cdot} \leftarrow \lambda_k\, g_{m,k,\cdot},
  \label{eq:zono_relu}
\end{equation}
with a new generator column appended that carries $\mu_k$ at row $k$ and zero elsewhere. At every ReLU layer we extract the per-neuron hull $(l_k, u_k)$ from Eq.~\eqref{eq:zono_hull} \emph{before} the relaxation overwrites the row, and inject these as the tightened pre-activation interval $[l_{m,k}, u_{m,k}]$ for the big-$M$ constants on neuron $(m,k)$.

When a prior verification of a structurally similar network $N_\text{pre}$ is available, we tighten $N$'s bounds further by propagating the weight drift between $N_\text{pre}$ and $N$ through the same zonotope abstraction.

Given $N_\text{pre}$'s per-neuron bounds and the weight and baises differences
 $\Delta W = W - W_\text{pre}, \Delta B = B - B_\text{pre}$, 
we compute a sound interval $[d^\downarrow_{m,k}, d^\uparrow_{m,k}]$ on the per-neuron 
pre-activation difference $\hat z^{N}_{m,k} - \hat z^{N_\text{pre}}_{m,k}$ by 
propagating $\Delta W$ and $\Delta B$ through the network. Combined with $N_\text{pre}$'s known bounds, 
this yields tighter pre-activation bounds for $N$:
\begin{equation}
  l^{N}_{m,k} \ge l^{N_\text{pre}}_{m,k} + d^\downarrow_{m,k},
  \quad
  u^{N}_{m,k} \le u^{N_\text{pre}}_{m,k} + d^\uparrow_{m,k}.
  \label{eq:bt_combine}
\end{equation}
%These tightened bounds are injected as $N_2$'s big-$M$ constants, eliminate binaries on newly stable neurons, and also feed the per-copy triangle drop and sibling-gated refinement techniques when they execute on $N_2$.

We propogate $\Delta W$ and $\Delta B$ from the previous layer to calculate the differences for current layer $m$. 
Writing $\Delta w_{m,k,k'} = w_{m,k,k'} - w^\text{pre}_{m,k,k'}$ and $\Delta b_{m,k} = b_{m,k} - b^\text{pre}_{m,k}$ 
for the per-edge weight and bias drift, the decomposition at an affine layer is
\begin{align}
  \hat z^{N}_{m,k} - \hat z^{N_\text{pre}}_{m,k}
  \;=\;& \sum_{k'} w_{m,k,k'} \bigl(z^{N}_{m-1,k'} - z^{N_\text{pre}}_{m-1,k'}\bigr) \nonumber\\
  &+ \sum_{k'} \Delta w_{m,k,k'}\, z^{N_\text{pre}}_{m-1,k'} + \Delta b_{m,k},
  \label{eq:bt_decomp}
\end{align}
%where the first sum is the propagated diff and the second sum plus $\Delta b_{m,k}$ is the direct weight-drift contribution. The post-ReLU range of $N_1$'s preceding layer is $z^{N_1}_{m-1,k'} \in [\max(0, l^{N_1}_{m-1,k'}),\, \max(0, u^{N_1}_{m-1,k'})]$ (the ReLU clip of $N_1$'s known pre-activation interval).

We bound it with a zonotope abstraction,  in the same spirit as the absolute zonotope above, 
but applied to the diff. We represent the per-neuron diff 
$d_{m,k} \triangleq \hat z^{N}_{m,k} - \hat z^{N_\text{pre}}_{m,k}$ 
as a centre plus a linear combination of shared noise variables $\eta_j \in [-1, 1]$, 
stored as a centre vector $\mathbf c_m \in \RR^K$ and a generator matrix $G_m \in \RR^{K \times p}$ 
with per-neuron hull.
\begin{equation}
  [d^\downarrow_{m,k}, d^\uparrow_{m,k}] = \bigl[c_{m,k} - \textstyle\sum_j |g_{m,k,j}|,\; c_{m,k} + \textstyle\sum_j |g_{m,k,j}|\bigr].
  \label{eq:bt_zono_hull}
\end{equation}
Both networks receive the same input, so we initialise at the 
input with zero diff and no generators, $\mathbf c_0 = \mathbf 0_n$ and $G_0 = \mathbf 0_{n \times 0}$. 
The affine update is evaluated at the midpoint $\mathrm{mid}_{m-1}$ and half-width
$\mathrm{rad}_{m-1}$ of $N_\text{pre}$'s post-ReLU range
$R^{N_\text{pre}}_{m-1,k'} \triangleq [\underline a_{m-1,k'},\, \overline a_{m-1,k'}]$, where
$\underline a_{m-1,k'} \triangleq \max(0, l^{N_\text{pre}}_{m-1,k'})$ and
$\overline a_{m-1,k'} \triangleq \max(0, u^{N_\text{pre}}_{m-1,k'})$ are the ReLU-clipped
pre-activation bounds of $N_\text{pre}$:
\begin{align}
  \mathrm{mid}_{m-1,k'} &= \tfrac{1}{2}\bigl(\overline a_{m-1,k'} + \underline a_{m-1,k'}\bigr), \nonumber\\
  \mathrm{rad}_{m-1,k'} &= \tfrac{1}{2}\bigl(\overline a_{m-1,k'} - \underline a_{m-1,k'}\bigr),
  \label{eq:bt_midrad}
\end{align}
stacked over $k'$ into the vectors $\mathrm{mid}_{m-1}$ and $\mathrm{rad}_{m-1}$ used below.
The centre then carries the propagated diff centre plus the direct weight-drift
contribution evaluated at this midpoint, and the generator matrix
concatenates the propagated generators with a fresh diagonal block of independent generators
scaled by $\Delta W$ and the post-ReLU half-widths:
\begin{align}
  \mathbf c_m &= W\, \mathbf c_{m-1} + \Delta W \cdot \mathrm{mid}_{m-1} + \Delta b_m, \nonumber\\
  G_m &= \bigl[\,W\, G_{m-1} \;\big|\; \Delta W \cdot \mathrm{diag}(\mathrm{rad}_{m-1})\,\bigr],
  \label{eq:bt_zono_affine}
\end{align}
At a ReLU layer, the per-neuron hull from Eq.~\eqref{eq:bt_zono_hull} drives the same DeepZ relaxation 
of Eq.~\eqref{eq:zono_relu}, and we read $[d^\downarrow_{m,k}, d^\uparrow_{m,k}]$ at each ReLU site 
for use in Eq.~\eqref{eq:bt_combine}.

The diff zonotope bounds $N$ relative to $N_\text{pre}$. We tighten further with a second, 
independent zonotope that bounds $N$'s \emph{absolute} pre-activations, propagating through $N$ 
alone, with the input-covering initialisation of Eq.~\eqref{eq:zono_init}, the affine and DeepZ
updates, and the per-neuron hull of Eq.~\eqref{eq:zono_hull} all exactly as above, only applied to $N$ rather than to the two-copy encoding. We write
$[l^{\mathrm{zono}(N)}_{m,k}, u^{\mathrm{zono}(N)}_{m,k}]$ for the resulting hull 
of Eq.~\eqref{eq:zono_hull} on $N$'s absolute pre-activation $\hat z^{N}_{m,k}$, 
and intersect it with the diff-based bound of Eq.~\eqref{eq:bt_combine} by 
keeping the tighter of the two at every neuron:
\begin{align}
  l^{N}_{m,k} &= \max\!\bigl(l^{\mathrm{zono}(N)}_{m,k},\; l^{N_1}_{m,k} + d^\downarrow_{m,k}\bigr), \nonumber\\
  u^{N}_{m,k} &= \min\!\bigl(u^{\mathrm{zono}(N)}_{m,k},\; u^{N_1}_{m,k} + d^\uparrow_{m,k}\bigr).
  \label{eq:bt_srcB}
\end{align}
We then propagate these intersected bounds through the absolute zonotope's DeepZ relaxation, so each layer passes through a narrower tube.

Both zonotopes are sound abstract interpretations, so each per-neuron hull contains 
every realisable value of its quantity. The intersection in Eq.~\eqref{eq:bt_srcB} of 
two sound over-approximations is itself sound.

\paragraph{Linear Abstraction Over Two Networks.}
\label{sec:tech:transfer_relax}

For each split ReLU neuron with pre-activation bounds $[l, u]$, the area of its triangle LP relaxation is $\mathrm{gap}(l, u) = u\,|l| / \bigl(2(u - l)\bigr)$. Per-copy triangle drop replaces the binary $a$ and its big-$M$ constraints with the three triangle inequalities on every (neuron, copy) whose gap is below a user-specified threshold $\tau$, leaving the other neurons with their exact encoding. The result is a sound upper bound $\delta \ge \dexact$ that approaches $\dexact$ as $\tau$ decreases (equality at $\tau = 0$).

Per-copy triangle drop drops the binary on a copy whenever that copy's gap is below the threshold $\tau$. Writing $g^{\mathrm{o}} \triangleq \mathrm{gap}(l^{\mathrm{org}}_{m,k}, u^{\mathrm{org}}_{m,k})$ and $g^{\mathrm{p}} \triangleq \mathrm{gap}(l^{\mathrm{pert}}_{m,k}, u^{\mathrm{pert}}_{m,k})$ for the two per-copy gaps (the $(m,k)$ indices are implicit), every split ReLU neuron falls into one of four tiers:
\begin{equation}
\mathrm{tier} = \begin{cases}
  \text{both-thin}, & g^{\mathrm{o}}\!,\, g^{\mathrm{p}} \!<\! \tau, \\
  \text{one-thin}^{\mathrm{org}}, & g^{\mathrm{o}} \!<\! \tau \!\le\! g^{\mathrm{p}}, \\
  \text{one-thin}^{\mathrm{pert}}, & g^{\mathrm{p}} \!<\! \tau \!\le\! g^{\mathrm{o}}, \\
  \text{neither}, & g^{\mathrm{o}}\!,\, g^{\mathrm{p}} \!\ge\! \tau.
\end{cases}
\label{eq:sg_tiers}
\end{equation}
The superscript on $\text{one-thin}^{\mathrm{org}}$ (resp.\ $\text{one-thin}^{\mathrm{pert}}$) marks which copy is relaxed.
In the both-thin tier, per-copy triangle drop drops both binaries; in either one-thin tier, it drops only the relaxed copy's binary and keeps the sibling's binary exact; in the neither tier, both binaries stay.

The relexation augments per-copy triangle drop's emission in two ways. 
In the one-thin tier, the relaxed copy's simple triangle ignores 
the surviving sibling binary on the kept copy, even though that binary carries an exact 
$\{0, 1\}$ value. Conditioning the relaxed copy's envelope on this sibling binary yields a strictly 
tighter LP relaxation, since each sibling branch forces a sub-interval of the unconditional pre-activation 
bound on the relaxed copy; we therefore replace the simple triangle with two big-$M$-gated conditional triangles, 
one per sibling branch. In the both-thin tier, we additionally inject a single pre-activation coupling 
line linking the two relaxed copies.

We write the one-thin equations for the org-relaxed sub-case; the pert-relaxed sub-case is the mirror image, with org and pert swapped throughout. From per-copy pre-activation bounds $[l^{\mathrm{org}}_{m,k}, u^{\mathrm{org}}_{m,k}]$ and $[l^{\mathrm{pert}}_{m,k}, u^{\mathrm{pert}}_{m,k}]$ (see Zonotope Bound Tightening) and the pre-activation drift interval $[\Delta^{z,\downarrow}_{m,k}, \Delta^{z,\uparrow}_{m,k}]$ for $\hat z^{\mathrm{pert}}_{m,k} - \hat z^{\mathrm{org}}_{m,k}$ (Eq.~\eqref{eq:pi_affine}, read at the pre-ReLU site, before the clip of Eq.~\eqref{eq:pi_relu}), we compute the conditional bounds
\begin{align}
  l_A &= \max\!\bigl(-\Delta^{z,\uparrow}_{m,k},\, l^{\mathrm{org}}_{m,k}\bigr), \\
  u_A &= \min\!\bigl(u^{\mathrm{pert}}_{m,k} - \Delta^{z,\downarrow}_{m,k},\, u^{\mathrm{org}}_{m,k}\bigr),
  \label{eq:sg_lAuA}\\
  l_I &= \max\!\bigl(l^{\mathrm{pert}}_{m,k} - \Delta^{z,\uparrow}_{m,k},\, l^{\mathrm{org}}_{m,k}\bigr), \\
  u_I &= \min\!\bigl(-\Delta^{z,\downarrow}_{m,k},\, u^{\mathrm{org}}_{m,k}\bigr).
  \label{eq:sg_lIuI}
\end{align}
Each pair is a strict sub-interval of $[l^{\mathrm{org}}_{m,k}, u^{\mathrm{org}}_{m,k}]$: $[l_A, u_A]$ is the active-sibling branch ($a^{\mathrm{pert}}_{m,k} = 1$, so $\hat z^{\mathrm{pert}}_{m,k} \ge 0$), and $[l_I, u_I]$ is the inactive-sibling branch ($a^{\mathrm{pert}}_{m,k} = 0$, so $\hat z^{\mathrm{pert}}_{m,k} \le 0$).

On the relaxed org copy, we replace per-copy triangle drop's simple triangle with the four inequalities
\begin{align}
  z^{\mathrm{org}}_{m,k} &\ge 0, \quad z^{\mathrm{org}}_{m,k} \ge \hat z^{\mathrm{org}}_{m,k},
  \label{eq:sg_lower}\\
  z^{\mathrm{org}}_{m,k} &\le \tfrac{u_A}{u_A - l_A}\bigl(\hat z^{\mathrm{org}}_{m,k} - l_A\bigr) \nonumber\\
    &\quad + M\,(1 - a^{\mathrm{pert}}_{m,k}),
  \label{eq:sg_active}\\
  z^{\mathrm{org}}_{m,k} &\le \tfrac{u_I}{u_I - l_I}\bigl(\hat z^{\mathrm{org}}_{m,k} - l_I\bigr) \nonumber\\
    &\quad + M\,a^{\mathrm{pert}}_{m,k},
  \label{eq:sg_inactive}
\end{align}
with $M = u^{\mathrm{org}}_{m,k} + |l^{\mathrm{org}}_{m,k}|$ a big-$M$ slack chosen large enough to make the off-branch upper bound vacuous over the feasible region. When $a^{\mathrm{pert}}_{m,k} = 1$, Eq.~\eqref{eq:sg_active} enforces the tighter $[l_A, u_A]$ triangle while Eq.~\eqref{eq:sg_inactive} is slack; the roles swap when $a^{\mathrm{pert}}_{m,k} = 0$. No new variables are introduced beyond the existing $z^{\mathrm{org}}_{m,k}$ and $\hat z^{\mathrm{org}}_{m,k}$, since the surviving binary $a^{\mathrm{pert}}_{m,k}$ already lives in the pert copy's exact big-$M$ encoding.

For a both-thin neuron, both copies receive the simple triangle of per-copy triangle drop and we additionally emit one pre-activation coupling line,
\begin{equation}
  \Delta^{z,\downarrow}_{m,k} \le \hat z^{\mathrm{pert}}_{m,k} - \hat z^{\mathrm{org}}_{m,k} \le \Delta^{z,\uparrow}_{m,k},
  \label{eq:sg_coupling}
\end{equation}
the pre-ReLU analogue of the post-activation coupling in Eqs.~\eqref{eq:pi_upper}--\eqref{eq:pi_lower}, which prevents the LP relaxation from choosing the two copies' pre-activations independently. Eqs.~\eqref{eq:sg_lAuA}--\eqref{eq:sg_lIuI} intersect two independently sound sources, so on whichever sibling branch the binary lands the gated triangle in Eqs.~\eqref{eq:sg_active}--\eqref{eq:sg_inactive} still envelopes the exact ReLU output. The resulting bound $\delta \ge \dexact$ is no looser than per-copy triangle drop's, and strictly tighter on every node of Gurobi's branch tree that fixes the surviving sibling binary when the two sources disagree.

So far we drove per-copy triangle drop and sibling-gated refinement with $N$'s own per-neuron bounds. When a prior verification of a structurally similar network $N_\text{pre}$ is available, the techniques are unchanged, but the per-copy bounds $[l^{N,\mathrm{copy}}_{m,k}, u^{N,\mathrm{copy}}_{m,k}]$, $\mathrm{copy} \in \{\mathrm{org}, \mathrm{pert}\}$, that drive their gap test become $N$'s \emph{transfer-tightened} bounds from Zonotope Bound Tightening (Eqs.~\eqref{eq:bt_combine} and~\eqref{eq:bt_srcB}): the intersection of $N_\text{pre}$'s reused per-copy bound plus the weight-drift diff with $N$'s absolute zonotope hull. This changes the technique in three ways:
\begin{itemize}[noitemsep,topsep=2pt]
  \item \textbf{Which binaries drop.} The gap test
    $\mathrm{gap}(l^{N,\mathrm{copy}}_{m,k}, u^{N,\mathrm{copy}}_{m,k}) < \tau$ is evaluated on the bounds we
    actually write into $N$'s MIP, so it inherits the tightening that $N_\text{pre}$'s prior verification
    provides. As the transfer bounds are contained in $N$'s standalone zonotope hull, at least as many neurons
    qualify as near-decided.
  \item \textbf{The org/pert asymmetry.} The two copies' gaps can differ because $N_\text{pre}$'s reused
    per-copy bounds differ: the perturbed copy inherits a wider input box, so a neuron may be thin on one copy
    and fat on the other even where the weight-drift diff is identical.
  \item \textbf{The conditional triangles.} Sibling-gated refinement builds its gated envelopes from these
    same transfer-tightened per-copy bounds, intersected with the org/pert pre-activation drift propagated
    through $N$.
\end{itemize}

\paragraph{Suboptimal Lower Bound and Variable Hints.}
\label{sec:tech:vh}

We apply VHAGAR's variable hinting technique to $N$'s MIP and suboptimal lower bound, with a modification for transfer mode.
We run a pgd optimization process to compute a lower bound for $\delta^*$ which is added to as a constraint to the MIP problem.
VHAGaR derives the initial binary hints from this PGD solution: each split ReLU is active or inactive 
at the returned perturbation, and VHAGaR sets the neuron's binary to that activation state as a warm-start for the MIP.
We modify this process for transfer mode by additionally deriving a hint value from $N_\text{pre}$'s 
optimum analysis, which is a feasible point of $N$'s MIP and may be close to $N$'s own optimum.

From $N_\text{pre}$'s analysis we read, for each split ReLU neuron $i$, its activation
$v^{N_\text{pre}}_i \in \{0,1\}$ ($1$ if active) and its pre-activation $\hat z^{N_\text{pre}}_i$.
We compute the transfer probability $p_i \in [0, 1]$ from a heuristic interval $\tilde I_i$ that
shifts $\hat z^{N_\text{pre}}_i$ by the weight-drift diff and intersects with $N$'s tightened
bound $[l^N_i, u^N_i]$:
\begin{equation}
  I_i = [\hat z^{N_\text{pre}}_i + d^\downarrow_i,\, \hat z^{N_\text{pre}}_i + d^\uparrow_i],
  \quad
  \tilde I_i = I_i \cap [l^{N}_i,\, u^{N}_i],
  \label{eq:vh_interval}
\end{equation}
Here $\hat z^{N_\text{pre}}_i$ is recovered from $N_\text{pre}$'s analysis. 
%: when the neuron is active ($v^{N_\text{pre}}_i = 1$) its pre-activation equals the recorded post-ReLU value. When it is inactive ($v^{N_\text{pre}}_i = 0$) the primal pins only the post-ReLU value to $0$ and leaves the pre-activation in $[l^{N_\text{pre}}_i, 0]$, so we take the midpoint $l^{N_\text{pre}}_i / 2$.
The transfer probability $p_i$ is the fraction of $\tilde I_i$ on the side of zero consistent with $N_\text{pre}$'s decision ($\hat z \ge 0$ if active, $\hat z \le 0$ if inactive),
\begin{equation}
  p_i = \begin{cases}
    \dfrac{|\tilde I_i \cap (-\infty, 0]|}{|\tilde I_i|}, & v^{N_\text{pre}}_i = 0, \\[8pt]
    \dfrac{|\tilde I_i \cap [0, +\infty)|}{|\tilde I_i|}, & v^{N_\text{pre}}_i = 1,
  \end{cases}
  \label{eq:vh_p}
\end{equation}
where $|\cdot|$ denotes interval length, so $p_i$ is the fraction of $\tilde I_i$ that still backs $N_\text{pre}$'s decision. We keep $N_\text{pre}$'s value when $p_i \ge 0.5$ and flip it otherwise:
\begin{equation}
  \mathtt{hint\_val}(a_i) =
    \begin{cases}
      v^{N_\text{pre}}_i, & p_i \ge 0.5, \\
      1 - v^{N_\text{pre}}_i, & p_i < 0.5.
    \end{cases}
  \label{eq:vh_val}
\end{equation}
The hyper-adversarial attack has already populated Gurobi's warm-start $\mathrm{Start}(a_i)$ on some 
binaries. We deliver $\mathtt{hint\_val}(a_i)$ through the same channel using a 
three-way consensus filter against any existing entry: 
(i)~\emph{fill} when PGD left $\mathrm{Start}(a_i)$ unset, by setting $\mathrm{Start}(a_i) 
\leftarrow \mathtt{hint\_val}(a_i)$; (ii)~\emph{leave} when PGD's value already matches 
$\mathtt{hint\_val}(a_i)$; (iii)~\emph{withdraw} when PGD's value disagrees with 
$\mathtt{hint\_val}(a_i)$, by clearing $\mathrm{Start}(a_i)$ back to unset.
